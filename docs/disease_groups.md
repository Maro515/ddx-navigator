# 疾患群（病理・特殊検査でしか区別できない疾患のまとめ）

- 作成日: 2026-09-27（オーナー指定）
- 方針: 確定に病理（生検・切除標本）か特殊な血液・尿検査が必要な疾患は、このアプリでは区別せず 1 つの疾患群として扱う。
- ルーチンの情報（問診・診察・一般採血・画像・内視鏡の肉眼所見）で区別できるものは別疾患のまま残す。
- 定義: `tools/feature_defs.json` の `disease_groups`、統合は `tools/disease_alias.json`。群の有病率は構成疾患の概算の合計（`tools/prevalence.json`）。
- 群に含まれる疾患の所見はすべて群に引き継ぐ（どれか1つの疾患の所見に合えば群を支持）。診断的所見も同じ。

## 特殊検査の扱い

ガストリン、尿中ポルホビリノーゲン、便中α1-アンチトリプシン、尿中5-HIAA、メタネフリン、セルロプラスミン、sIL-2R、IgG4、自己抗体、ビタミンB12、フェリチン/トランスフェリン飽和度は「特殊検査」とし、次に調べる候補では一般検査より後ろに並ぶ（費用・待ち時間を高く設定）。入力されれば群の支持には使う。

## 別疾患のまま残したもの（判断の余地あり。ご確認ください）

| 対象 | 残した理由 |
|---|---|
| 食道癌 と 胃の腫瘍性病変 | 内視鏡で臓器が分かる。ただし食道の平滑筋腫は「GIST/粘膜下腫瘍」に含まれるため胃の群に入っている |
| 肝細胞癌・肝内胆管癌・転移性肝癌・肝良性腫瘍 | 造影パターン（動脈相濃染/washout、辺縁結節状濃染、リング状造影）、腫瘍マーカー、原発巣の既往で区別できることが多い |
| 大腸癌 と 小腸・消化管の腫瘍 | 部位（大腸内視鏡/CT）で区別できる |
| 原発性硬化性胆管炎 と IgG4関連疾患 | 年齢・炎症性腸疾患の合併・MRCP所見で区別できることが多い（厳密には IgG4 と病理が必要） |
| 炎症性腸疾患、腸結核、CMV腸炎 | 内視鏡像・免疫抑制の有無・培養/IGRA で区別し、治療が大きく異なる |
| 好酸球性胃腸炎、消化管アミロイドーシス、蛋白漏出性胃腸症 | 末梢血好酸球・基礎疾患・低アルブミンと尿蛋白なし、でおおよそ区別できる |
| 慢性胃炎（ピロリ・自己免疫性）と 胃の腫瘍性病変 | 内視鏡で腫瘍か炎症かは区別できる |
| 虫垂神経内分泌腫瘍（小腸・消化管の腫瘍の群）と 急性虫垂炎 | 術後の病理でしか分からないが、術前の対応は虫垂炎と同じため、あえて統合していない |
