# 所見項目の重複候補レビュー（拡張パック 85 項目）

- 作成日: 2026-09-27
- 対象: KB `abd-pack-0.2.1`（コア 82 項目）＋拡張パック `abd_ext`（新規 85 項目）＝ 167 項目
- 目的: 資料の章ごとに別々に作られた所見項目の重複を洗い出し、統合先を決める。承認欄に ○/× を付けて返してもらえれば、`tools/feature_alias.json` と生成器に反映する。

## 方法

| 指標 | やり方 | 件数 |
|---|---|---|
| 語彙の相互ヒット | 各項目のラベル語・値ラベルを「〜あり。」の文にしてローカル解析に通し、別の項目が立つかを見た | 744 文中 77 件 |
| ラベル・値ラベルの類似 | 文字 2-gram の Jaccard 係数と、語の包含（「脂肪便」が両方に含まれる等） | 109 組 |
| 二重計上 | 候補の組の両方を同じ疾患が参照しているか（両方が立つと同じ所見の尤度比を 2 回掛ける） | 下表に記載 |

「腹部」「腫瘤」「既往」のような共通語だけで一致した組（例: 放射線治療歴 × 腹部CT）は除外し、残りを臨床的に 7 区分に分けた。

重複の害は 2 種類ある。

1. **二重計上**: ローカル解析が両方の項目を立てると、同じ所見で 2 回加点される。
2. **重複質問**: 片方しか立たないと、もう片方が「未確認」のまま残り、同じことを別の言葉で再度質問される。

|---|---|---|

| 脾腫 | `ct_other` の「脾梗塞/脾腫/脾破裂」「肝脾腫」、`hb_imaging` の「肝硬変像/脾腫」 | なし |

加えて「CTで肝腫瘤」と書いたとき、どの項目に入るかが決まらない。

**提案（推奨）**

- `ct_other` と `ct_wall_mass` の値をすべて `ct` に吸収し、腹部CT を 1 項目にする。
- `hb_imaging` も `ct` の値として吸収する。超音波で見える所見は既存の `us` の値に対応させる（胆管拡張→総胆管拡張、胆嚢壁肥厚→胆嚢腫大/壁肥厚、腹水→腹水/骨盤内液体）。
- 値の整理:
  - 腸重積、肝腫瘤、門脈血栓、腹水はそれぞれ 1 値にする。
  - 「腫瘤」は `ct_wall_mass`（腸管腫瘤）と `ct_other`（腹腔内/後腹膜腫瘤）で意味が違うので、別の値名にする。
  - 「脾梗塞/脾腫/脾破裂」は脾梗塞と脾破裂に分け、脾腫は「肝脾腫」にまとめる。「肝硬変像/脾腫」から脾腫を外す。
  - 「腸腰筋膿瘍/腹腔内膿瘍」は既存の CT「膿瘍」に統合してよいか要判断。
- 影響: 腹部CT の値が約 45 個になる。質問カードは値が 7 個以上だと「入力欄に書く」になる既存の仕様なので、画面は変わらない。

**代案**: `hb_imaging` を「検査法を問わない肝胆膵の画像所見」として残し、CT 系 3 項目だけを統合する。作業は軽いが、`us` との胆管拡張の重複は残る。
